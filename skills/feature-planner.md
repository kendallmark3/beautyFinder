# Feature Planner Skill
Break features into implementation steps.

For a feature file in `intent/features/`:
1. List each acceptance criterion.
2. For each AC: the test that proves it, then the code that satisfies it.
3. Confirm every file touched is inside Scope.
4. Order the steps so tests are always written before the code they prove.

(Claude Code version of this lives in `.claude/commands/run-intent.md` step 3.)
