# Glossary

- **Depth**: how light or deep skin is, on a 1–10 scale.
- **Undertone**: cool, neutral, or warm hue under the skin surface.
- **Shade code**: three-digit shade id (e.g. 230). The first digit groups depth families.
- **Consultation**: a recommendation to see an in-store beauty advisor when no shade is close.
- **Feature intent**: a file in `intent/features/` that defines one feature: goal, scope, rules, acceptance criteria.
- **Evidence pack**: the proof a feature is done, kept in `evidence/<feature-id>/`.
